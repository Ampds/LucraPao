Requisitos do LucraPão

Requisitos Funcionais

RF01 — Cadastrar ingredientes



O sistema deve permitir o cadastro de ingredientes, informando nome, unidade de medida e preço.



RF02 — Cadastrar produtos



O sistema deve permitir o cadastro de produtos que serão comercializados pelo produtor.



RF03 — Cadastrar receitas



O sistema deve permitir associar ingredientes e suas respectivas quantidades a uma receita.



RF04 — Calcular custo do produto



O sistema deve calcular o custo de produção do produto com base nos ingredientes e quantidades utilizados na receita.



RF05 — Informar preço de venda



O sistema deve permitir informar o preço de venda de cada produto.



RF06 — Calcular lucro estimado



O sistema deve calcular o lucro estimado com base no custo de produção e no preço de venda.



RF07 — Consultar produtos e informações financeiras



O sistema deve permitir consultar os produtos cadastrados, seus custos, preços de venda e lucros estimados.



RF08 — Editar informações



O sistema deve permitir alterar informações de ingredientes, produtos e receitas cadastrados.



RF09 — Excluir informações



O sistema deve permitir excluir ingredientes, produtos e receitas cadastrados.



Requisitos Não Funcionais

RNF01 — Usabilidade



A interface deve ser simples e intuitiva, facilitando o uso por pequenos produtores de alimentos.



RNF02 — Responsividade



A aplicação deve se adaptar adequadamente a diferentes tamanhos de tela.



RNF03 — Clareza das informações



Os valores de custo, preço de venda e lucro devem ser apresentados de forma clara ao usuário.



RNF04 — Tecnologia



A aplicação deve ser desenvolvida utilizando React Native com Expo.



RNF05 — Comunicação com a API



A aplicação deve ser capaz de se comunicar com a API responsável pelo armazenamento e processamento dos dados.
